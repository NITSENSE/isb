**Тема: Принципы построения гибридных криптографических систем на примере связки алгоритмов RSA и IDEA.**

**Введение: Назначение гибридных криптосистем**

В современной криптографии для обеспечения конфиденциальности данных применяются два основных класса систем: симметричные и асимметричные. Каждый из них обладает своими преимуществами и недостатками, что обуславливает необходимость их совместного использования в рамках гибридных систем.

**1. Симметричные криптосистемы**

Принцип работы симметричных систем заключается в использовании одного и того же секретного ключа как для шифрования, так и для дешифрования данных.

*   **Преимущества:** Высокая скорость выполнения операций. Это делает их оптимальным выбором для шифрования больших объемов информации, таких как файлы, базы данных или медиапотоки.
*   **Недостатки:** Основная проблема заключается в безопасной передаче секретного ключа от отправителя к получателю. Если для передачи ключа не существует предварительно установленного защищенного канала, ключ может быть перехвачен третьей стороной, что полностью компрометирует всю последующую зашифрованную переписку.

**2. Асимметричные криптосистемы**

Асимметричные системы (или криптосистемы с открытым ключом) используют пару математически связанных ключей: открытый (public) и закрытый (private).

*   **Открытый ключ:** Может свободно распространяться. Он используется для шифрования сообщений, предназначенных владельцу ключевой пары.
*   **Закрытый (секретный) ключ:** Хранится в строжайшем секрете его владельцем. Только этот ключ может расшифровать данные, зашифрованные соответствующим ему открытым ключом.
*   **Преимущества:** Эффективно решается проблема безопасного распределения ключей. Отправителю достаточно знать общедоступный открытый ключ получателя, чтобы отправить ему защищенное сообщение.
*   **Недостатки:** Значительно более низкая производительность по сравнению с симметричными аналогами. Вычислительная сложность операций делает их непригодными для шифрования больших объемов данных.

**3. Гибридный подход: Комбинация преимуществ**

Гибридные криптосистемы объединяют сильные стороны обоих подходов для создания эффективной и безопасной схемы шифрования.

Схема работы гибридной системы:

1.  Для шифрования основного массива данных (например, файла) генерируется случайный симметричный ключ. Этот ключ называется **сеансовым (session key)**, так как его жизненный цикл ограничен одной сессией обмена данными.
2.  Исходное сообщение (большой объем данных) шифруется с помощью быстрого симметричного алгоритма с использованием сгенерированного сеансового ключа.
3.  Сам сеансовый ключ, имеющий малый размер, шифруется с помощью медленного, но криптостойкого асимметричного алгоритма с использованием **открытого ключа** получателя.
4.  Получателю отправляются два компонента:
    *   Зашифрованное симметричным алгоритмом основное сообщение.
    *   Зашифрованный асимметричным алгоритмом сеансовый ключ.

Для расшифровки получатель сначала использует свой **закрытый ключ** для дешифрования сеансового ключа. Затем, получив сеансовый ключ, он использует его для быстрой расшифровки основного сообщения.

Таким образом, гибридная система обеспечивает высокую скорость обработки больших объемов данных (за счет симметричного шифра) и одновременно решает проблему безопасной передачи ключа (за счет асимметричного шифра).

**1.2. Асимметричный компонент: Алгоритм RSA**

RSA (назван по фамилиям создателей: Rivest, Shamir, Adleman) — один из наиболее известных и широко применяемых асимметричных алгоритмов.

*   **Принцип работы:** Криптостойкость RSA основана на вычислительной сложности задачи факторизации больших целых чисел (разложения числа на простые множители). На основе этой сложности генерируется пара ключей: открытый и закрытый.
*   **Применение в лабораторной работе:** RSA будет использоваться для наиболее ответственной части — шифрования сеансового ключа, который, в свою очередь, будет использоваться для симметричного шифра IDEA.

---

**1.3. Симметричный компонент: Алгоритм IDEA (Вариант №9)**

IDEA (International Data Encryption Algorithm) — симметричный блочный шифр, разработанный в Швейцарии в начале 1990-х годов.

*   **Принцип работы:** IDEA является блочным шифром. Это означает, что он обрабатывает данные фиксированными блоками, а не побитово или побайтово. Для шифрования и дешифрования используется один и тот же секретный ключ.
*   **Характеристики IDEA (согласно варианту):**
    *   **Размер блока:** 64 бита (8 байт). Данные нарезаются на фрагменты по 8 байт для последующей обработки.
    *   **Длина ключа:** 128 бит (16 байт).
*   **Применение в лабораторной работе:** IDEA используется для выполнения основной задачи — шифрования и дешифрования содержимого текстового файла.

**Дополнительные механизмы, используемые с IDEA:**

*   **Режим сцепления блоков шифротекста (CBC - Cipher Block Chaining):**
    Этот режим предназначен для устранения уязвимости, при которой одинаковые блоки открытого текста преобразуются в одинаковые блоки шифротекста. В режиме CBC каждый блок открытого текста перед шифрованием комбинируется (посредством операции XOR) с предыдущим уже зашифрованным блоком. Для самого первого блока, у которого нет предыдущего, используется специальное случайное число — **вектор инициализации (IV - Initialization Vector)**. IV имеет размер, равный размеру блока (для IDEA — 8 байт), и должен быть уникальным для каждой операции шифрования. IV не является секретным и обычно передается вместе с шифротекстом.

*   **Механизм дополнения данных (Padding):**
    Блочные шифры могут корректно обрабатывать только те данные, длина которых кратна размеру блока. Если размер исходных данных не кратен 8 байтам (для IDEA), используется механизм дополнения. К концу данных добавляется определенное количество байт, чтобы их общая длина стала кратной размеру блока. После дешифрования эти дополнительные байты удаляются. В работе будет использоваться стандарт дополнения **ANSI X9.23**.

---

**1.4. Обзор сценариев лабораторной работы**

Программа должна реализовывать три основных режима работы:

**1. Генерация ключей гибридной системы:**
    *   Генерация симметричного ключа для алгоритма IDEA (128 бит).
    *   Генерация пары асимметричных ключей для алгоритма RSA (открытого и закрытого).
    *   Сохранение открытого и закрытого ключей RSA в отдельные файлы.
    *   Шифрование сгенерированного ключа IDEA с помощью открытого ключа RSA и сохранение результата в файл.

**2. Шифрование данных гибридной системой:**
    *   Чтение закрытого ключа RSA из файла.
    *   Чтение зашифрованного ключа IDEA из файла.
    *   Дешифрование ключа IDEA с помощью закрытого ключа RSA.
    *   Чтение исходного текстового файла.
    *   Шифрование текста файла с помощью ключа IDEA (с использованием режима CBC и механизма padding).
    *   Сохранение результата (вектор инициализации IV + зашифрованный текст) в новый файл.

**3. Дешифрование данных гибридной системой:**
    *   Чтение закрытого ключа RSA из файла.
    *   Чтение зашифрованного ключа IDEA из файла.
    *   Дешифрование ключа IDEA с помощью закрытого ключа RSA.
    *   Чтение зашифрованного файла.
    *   Извлечение вектора инициализации (IV) из начала файла.
    *   Дешифрование оставшейся части файла (шифротекста) с помощью ключа IDEA (с использованием IV и удалением padding).
    *   Сохранение расшифрованного текста в новый файл.

**Приложение: Детальное описание алгоритма IDEA**

*   **История:**
    Алгоритм разработан Джеймсом Мэсси и Сюэцзя Лаем (ETH Zurich) и представлен в 1991 году. Изначально разрабатывался как устойчивая к дифференциальному криптоанализу замена алгоритму DES.

*   **Структура и принцип работы:**
    IDEA — это блочный шифр, оперирующий 64-битными блоками данных и использующий 128-битный ключ. Структура алгоритма основана на 8 идентичных раундах преобразований и одной финальной выходной трансформации.
    Особенностью IDEA является использование в раундах трех различных, алгебраически несовместимых групповых операций над 16-битными подблоками, что значительно усложняет криптоанализ:
    1.  Побитовое исключающее ИЛИ (XOR).
    2.  Сложение по модулю 2^16.
    3.  Умножение по модулю (2^16 + 1).
    Из исходного 128-битного ключа по определенному алгоритму генерируются 52 раундовых подключа (по 16 бит каждый), которые используются на разных этапах шифрования.

*   **Криптостойкость:**
    На момент своего создания и в течение долгого времени после IDEA считался одним из самых надежных шифров. Он продемонстрировал высокую устойчивость к дифференциальному и линейному криптоанализу. Существуют теоретические атаки на урезанные версии алгоритма (с меньшим числом раундов) и атаки на связанные ключи, однако они малоприменимы в реальных условиях. Обнаружен также незначительный класс слабых ключей, вероятность случайной генерации которых пренебрежимо мала.
    На сегодняшний день IDEA все еще считается надежным, однако повсеместное распространение получил стандарт AES с большим размером блока (128 бит), который лучше подходит для шифрования сверхбольших объемов данных.

*   **Применение:**
    Наиболее известным применением IDEA является его использование в ранних версиях программы PGP (Pretty Good Privacy) для шифрования электронной почты и файлов. Также алгоритм находил применение в финансовых и банковских системах.
